# LearningAutomata.jl Documentation

LearningAutomata.jl provides types and methods to facilitate simulations of simple stochastic learning processes. The current implementation supplies such types and methods for the linear algorithm of [BushMosteller1955](@citet). However, LearningAutomata.jl also provides a framework and design philosophy for the inclusion of more complex learning schemes (see [Developer notes](@ref)) as well as [Agents.jl integration](@ref) for complex agent-based learning simulations.

To install:

```julia
]add https://github.com/hkauhanen/LearningAutomata.jl
```

Then read the [Quickstart](@ref) guide to jump right in!
